# Password Manager Shortcuts Configuration
# This file defines keyboard shortcuts that should be blocked from being sent to the remote machine
# These shortcuts trigger password manager autotype functions
#
# Format: MODIFIERS+KEY
# Modifiers: Ctrl, Alt, Shift (case insensitive)
# Keys: A-Z, 0-9, or special keys like Backslash
#
# Lines starting with # are comments
# Empty lines are ignored

# Remote Desktop Manager
